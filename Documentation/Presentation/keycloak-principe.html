How JWT security works

Proposed Spring Security flow. The client obtains a JWT and sends it with API requests. The gateway validates the token before routing the request. The team still needs to select the token issuer.

The eight steps

Getting and using the token

  • The user signs in through the configured token issuer.
  • The React app receives an access token and sends Authorization: Bearer <token>.
  • The gateway checks the signature, expiry, issuer and permissions before routing the request.
  • An authorised request reaches the target service and its response returns through the gateway.

Suggested configuration

  • Spring Security resource server at the gateway.
  • The team will choose the issuer, roles and token configuration during integration.
